# 🚀 Portfolio Website

A modern and responsive personal portfolio website built to showcase my projects, skills, and web development journey.

## 🌐 Live Demo

Visit the live website here:
Portfolio Live here : https://siamwd.github.io/portfolio/

## 📌 Features

* Responsive Design
* Modern UI/UX
* Portfolio Showcase
* Skills Section
* Contact Form
* Smooth Animations
* Mobile Friendly Layout

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Tailwind CSS
* Git & GitHub

## 📂 Project Structure

```bash
portfolio/
│── index.html
│── style.css
│── script.js
│── assets/
│── images/
```

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/siamwd/portfolio.git
```

Open the project folder:

```bash
cd portfolio
```

Run the project by opening `index.html` in your browser.
